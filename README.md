# My Node.js Project

A simple Node.js project initialized using npm.

## Features

* Basic JavaScript output using `console.log()`
* npm project initialization
* Start script configured in `package.json`
* Git version control and GitHub integration

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Run `npm start` in the terminal.

Hello from Node.js!
My first npm project is running.
